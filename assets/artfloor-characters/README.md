# Art Floor characters

Fashion-photo character references and cutouts used for dimensional (non-billboard) gallery patrons.

- `cutouts/` — RGBA studio cutouts from user fashion refs (Sep 9)
- `variants/` — hue-shifted outfit colorways for drastic variety
- `glb/` — optional offline human GLBs (Three.js example Soldier/Xbot; Mixamo-origin, used as secondary mesh variety with tinting)
- `roster.json` — kits + variants index

Characters are rendered as thick multi-angle photo meshes (front/side/back) plus high-detail procedural outfit meshes (dress, tuxedo, long coat, smock, streetwear, punk). Flat camera-facing billboards are not used.
