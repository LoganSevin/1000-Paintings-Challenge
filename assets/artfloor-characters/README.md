# Art Floor characters

Sculpted 3D gallery patrons are built procedurally in `js/ge-artfloor-3d.js`
(capsule/sphere body contours + calm solid materials). Photo cutouts / prism
cards are intentionally not used.

- `glb/` — optional offline human GLBs (Three.js Soldier / Xbot) kept for future
  mesh variety; the live Art Floor uses sculpted contour humanoids with
  eyedropper-style outfit palettes so the marble hall stays visually calm.
